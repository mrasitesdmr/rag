#   <tarife etiketi, PDF'teki gibi birebir> => <kalıp> || <kalıp> ...

# Etiket, tarife satırının değer hücresinden önceki kısmıdır. Tarifede girdisi olmayan satır D13'ü KALDI yapar.
# Kalıp bir Java düzenli ifadesidir. 1-9. bölümlerdeki her cümlede ve tablo satırında aranır; metin Türkçe
# küçük harfe çevrilmiş (I → ı, İ → i; "SWIFT" → "swıft"), boşlukları teke indirilmiş ve "bkz. X.Y" atıfları
# "bkz." olarak kısaltılmıştır. "Örnek:" ile başlayan paragraflar aranmaz.
# Karşılaştırma eşleşmenin bittiği yerden cümlenin ya da satırın sonuna kadar yapılır: oradaki ilk değer
# tarifedekiyle aynı türdense aynı olmalıdır (ücretsiz satırda ilk değer "ücretsiz/alınmaz/ücret almaz" olmalıdır).
# Kalıp, ücretin konusunu tarif eder; değerin kendisi kalıba yazılmaz.
